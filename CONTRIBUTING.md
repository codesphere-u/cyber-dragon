# Contributing

Thank you for helping make digital safety accessible.

1. Open an issue describing the problem or improvement.
2. Fork and create a focused branch.
3. Add tests, run `pytest`, and document changes.
4. Open a pull request; avoid real victims' messages, personal data, credentials, and live malicious URLs in examples.
5. Security findings must follow [SECURITY.md](SECURITY.md), not public issues.

We welcome translations, accessibility fixes, educational content, threat research, tests, and documentation.
