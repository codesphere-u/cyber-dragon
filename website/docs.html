Cyber Dragon Documentation

Run private on-device analysis via Next.js, Node.js CLI, or the stateless FastAPI microservice.

1. Web Workbench (apps/web)

cd apps/web
npm install
npm test
npm run benchmark
npm run dev

2. Developer CLI

node --experimental-strip-types bin/cyber-dragon.mjs scan "URGENT: Dial *21*0772112233# to prevent SIM deactivation"

3. FastAPI Microservice (services/threat-api)

cd services/threat-api
pytest -q
uvicorn app.main:app --host 127.0.0.1 --port 8000

4. PII-Redacting Incident Reports

POST /api/v1/incident-report and generateIncidentReport() scrub phone numbers, 4–8 digit PINs/OTPs, emails, USSD strings, and query tokens.
